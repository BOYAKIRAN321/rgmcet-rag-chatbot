# 🎓 RGMCET RAG Chatbot - Student Retrieval System

### 🔴 Live Demo: https://rgmcet-rag-chatbot-1.onrender.com/chat.html
### 🟢 API Status: https://rgmcet-rag-chatbot.onrender.com

An AI-powered chatbot using RAG + LLM to retrieve student academic data instantly.

## ✨ Features
- 📘 Student Details by ID
- 📝 Marks & Semester Results
- ❌ Backlog / Fail Analysis
- 📊 CGPA Calculation
- 🏆 Top Performers & Ranking

## 🛠️ Tech Stack
- Backend: Python, Flask, LangChain, FAISS
- Frontend: HTML, JS
- LLM: Groq / OpenAI
- Deployment: Render

## 💬 Try Queries:
- `details of 21091A0012`
- `failed subjects of 21091A0012`
- `CGPA of 21091A0012`
